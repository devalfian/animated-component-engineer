# Exploration and Design

## Brief decomposition

Translate subjective language into observable behavior.

| User phrase | Clarify as |
|---|---|
| "Fresh air" | Directional airflow, subtle particles, soft fabric/leaf response, cool visual palette |
| "Premium" | Restrained movement, deliberate spacing, controlled easing, low visual noise |
| "Interactive" | Explicit triggers, feedback, state transitions, keyboard/touch equivalents |
| "3D" | Perspective, depth layers, parallax, or actual 3D rendering—choose intentionally |

## Design sequence

1. Identify the content hierarchy and primary action.
2. Choose one dominant visual idea.
3. Define the idle state before adding motion.
4. Add interaction feedback and transitions.
5. Check whether motion clarifies the story.
6. Remove effects that compete with content.

## Avoid

- Animations that delay access to important content.
- Random motion with no relationship to user intent.
- Hover-only information.
- Multiple competing focal points.
- Unrequested sound, autoplay video, or heavy 3D dependencies.

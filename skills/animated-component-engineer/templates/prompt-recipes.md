# Prompt Recipes

## Build a component
"Inspect this repository first. Use the Animated Component Engineer workflow. Build [component] for [purpose]. Preserve existing conventions and dependencies. Specify states, responsive behavior, reduced-motion behavior, and verification."

## Explore directions
"Explore three materially different animation concepts for [component]. For each, describe the visual metaphor, user trigger, motion sequence, complexity, and recommended implementation engine. Do not code yet."

## Improve existing motion
"Audit the existing component's motion for clarity, accessibility, responsiveness, and performance. Identify issues first, then make the smallest coherent improvements. Do not redesign unrelated parts."

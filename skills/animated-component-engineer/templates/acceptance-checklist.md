# Acceptance Checklist

- [ ] Matches the agreed visual direction and layout.
- [ ] Initial state is understandable without waiting for animation.
- [ ] Hover, focus, active, and disabled states are handled where relevant.
- [ ] Touch devices have equivalent interactions.
- [ ] Reduced-motion preference is respected.
- [ ] Responsive behavior is intentionally designed.
- [ ] No console errors or missing assets.
- [ ] Listeners, timers, observers, and animation contexts are cleaned up.
- [ ] Lint, typecheck, and relevant tests have been run or limitations documented.
